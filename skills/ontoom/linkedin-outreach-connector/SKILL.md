# LinkedIn outreach connector

## Goal

Turn email pitches into short LinkedIn messages for editors.

## Inputs

Email pitch + prospect role

## Instructions

1. Compress to 300–500 characters
2. Lead with specific compliment/value
3. One clear CTA
4. Optional connection-note variant

## Output

Connection note + message

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
