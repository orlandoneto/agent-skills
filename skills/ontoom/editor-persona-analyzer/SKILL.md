# Editor persona analyzer

## Goal

Match guest-post pitch tone to a publisher's editorial voice.

## Inputs

Publisher about/guidelines + sample articles

## Instructions

1. Extract tone, audience, taboo topics
2. List preferred formats
3. Rewrite pitch to match voice
4. Suggest 3 on-brief titles

## Output

Persona card + adapted pitch

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
