# Testimonial link swap

## Goal

Identify tools the user already uses and draft testimonials in exchange for a homepage/customers link.

## Inputs

List of tools/vendors used + outcomes

## Instructions

1. Prioritize vendors with customer/logo pages
2. Write authentic testimonial with metrics if available
3. Ask politely for a dofollow/nofollow-as-appropriate credit link
4. Avoid fake claims

## Output

Vendor list + testimonial drafts

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
