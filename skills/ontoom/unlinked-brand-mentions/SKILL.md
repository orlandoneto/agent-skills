# Unlinked brand mentions

## Goal

Find brand/product mentions without links and draft link-request emails.

## Inputs

Brand names + aliases + known domains

## Instructions

1. Propose search queries for unlinked mentions
2. Classify mention type (news, forum, review)
3. Prioritize by authority and relevance
4. Draft personalized ask-for-link emails

## Output

Prioritized list + email templates

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
