# Local citation builder

## Goal

List local directories, associations, and guides for local SEO citations.

## Inputs

Business NAP + category + city

## Instructions

1. List priority citation sources by country/city
2. Check NAP fields to submit consistently
3. Flag duplicates/inconsistencies if data given
4. Order by impact for local pack

## Output

Citation checklist with NAP fields

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
