# Resource page prospector

## Goal

Find 'useful links' / resource pages in a niche via advanced search operators.

## Inputs

Niche + optional geo

## Instructions

1. Build operator queries (intitle:resources, inurl:links, etc.)
2. Filter for editorial/resource pages
3. Score relevance and linkability
4. Draft pitch offering the user's resource

## Output

Prospect list with queries used + pitch draft

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
