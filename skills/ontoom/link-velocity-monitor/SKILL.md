# Link velocity monitor

## Goal

Evaluate link gain/loss pace to spot anomalies or negative SEO.

## Inputs

Monthly referring-domain history

## Instructions

1. Plot/describe velocity
2. Flag unnatural spikes/drops
3. Separate lost vs new
4. Suggest investigation steps

## Output

Velocity summary + alerts

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
