# Title tag CTR optimizer

## Goal

Generate SEO titles within ~60 characters using clarity and curiosity.

## Inputs

## Instructions

1. Generate 8–12 variants
2. Check length and keyword placement
3. Avoid clickbait mismatch
4. Pick top 3 with rationale

## Output

Title candidates ranked
