# Review response generator

## Goal

Craft personalized review responses incorporating local terms naturally.

## Inputs

Reviews text + tone policy

## Instructions

1. Respond to positive and negative separately
2. Stay professional
3. Invite offline resolution for complaints
4. Light local relevance without spam

## Output

Response set

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
