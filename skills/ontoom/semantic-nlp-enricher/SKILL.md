# Semantic NLP enricher

## Goal

List entities/related terms from top results missing from the user's draft.

## Inputs

Draft + competitor notes

## Instructions

1. Extract entities/topics competitors cover
2. Mark missing must-haves vs nice-to-haves
3. Suggest natural insertions
4. Avoid stuffing

## Output

Enrichment checklist

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
