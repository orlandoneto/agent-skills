# Competitor spiking alert

## Goal

Explain a sudden competitor link spike and extract replicable tactics.

## Inputs

Competitor domain + spike window + sample new links

## Instructions

1. Cluster new referring pages by type
2. Identify campaigns (PR, tool, viral asset)
3. Separate toxic vs editorial
4. List ethical replication ideas

## Output

Spike analysis + playbook

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
