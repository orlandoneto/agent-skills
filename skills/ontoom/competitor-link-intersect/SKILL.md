# Competitor link intersect

## Goal

Find sites linking to multiple competitors but not the user.

## Inputs

3 competitor domains + user domain + optional backlink CSVs

## Instructions

1. If CSVs provided, compute intersection of referring domains
2. If not, describe how to export from Ahrefs/Moz/Semrush/DataForSEO
3. Exclude user domain and low-quality noise
4. Prioritize editorial opportunities

## Output

Intersect list ranked by opportunity

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
