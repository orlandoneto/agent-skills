# Cold outreach personalizer

## Goal

Read a prospect's recent posts and write a highly personalized outreach email.

## Inputs

Prospect URL/blog + user's ask + asset

## Instructions

1. Summarize 2–3 recent pieces
2. Tie the ask to a specific paragraph or gap
3. Write short personalized email (no fluff)
4. Offer clear mutual value

## Output

Email draft + personalization notes

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
