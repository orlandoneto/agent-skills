# SEO meta audit

## Instructions

1. Ask for the URL or the HTML/head snippet if not provided.
2. Check presence and quality of:
   - `<title>` (length ~50–60 chars, primary keyword near start)
   - `meta name="description"` (~140–160 chars, actionable)
   - canonical URL
   - hreflang (if multi-locale)
   - Open Graph / Twitter cards
3. Flag duplicate titles, missing description, or thin copy.
4. Suggest concrete rewrites in the page language (default pt-BR unless asked).
5. Do not invent rankings or Search Console data you cannot see.

## Output

- Checklist pass/fail
- Suggested title + description
- Risks (duplicate, noindex, wrong canonical)
