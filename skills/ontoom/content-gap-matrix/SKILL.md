# Content gap matrix

## Goal

Compare competitor Top-10 keywords against the user's site coverage.

## Inputs

Competitor keyword exports + user's URL inventory

## Instructions

1. Find missing topics
2. Score difficulty vs opportunity
3. Suggest brief priorities
4. Avoid duplicate existing coverage

## Output

Gap matrix prioritized

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
