# Internal link injector

## Goal

Suggest exact places in old posts to link to a new article.

## Inputs

New URL + inventory of related posts (or sitemap notes)

## Instructions

1. Match topical relevance
2. Propose anchor + sentence context
3. Balance link equity (not spammy)
4. List updates prioritized

## Output

Internal link insertion list

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
