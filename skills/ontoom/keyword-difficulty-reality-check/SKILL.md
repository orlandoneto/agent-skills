# Keyword difficulty reality check

## Goal

Manually assess page-one competitiveness beyond a single KD score.

## Inputs

Target keyword + SERP notes/screenshots

## Instructions

1. Profile top results (DR, intent match, content depth)
2. Estimate realistic chance
3. Suggest supporting tactics or easier variants
4. Decide go/hold

## Output

Go/no-go memo

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
