# Sitemap XML auditor

## Goal

Compare sitemap URLs vs indexed/crawled pages for 404s, redirects, noindex mistakes.

## Inputs

Sitemap URLs + crawl/index notes

## Instructions

1. Find mismatches
2. Flag non-200 and noindex in sitemap
3. Prioritize fixes
4. Suggest split sitemaps if huge

## Output

Sitemap audit report

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
