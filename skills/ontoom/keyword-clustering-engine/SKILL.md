# Keyword clustering engine

## Goal

Cluster keywords by semantic similarity and search intent to avoid cannibalization.

## Inputs

Keyword list (CSV)

## Instructions

1. Group by intent and topic
2. Pick primary URL per cluster
3. Flag cannibalization risks
4. Suggest content types

## Output

Cluster map with primary keywords

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
