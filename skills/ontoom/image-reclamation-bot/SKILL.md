# Image reclamation

## Goal

Locate sites using the user's images without credit and request attribution/links.

## Inputs

Image URLs or reverse-search notes + preferred credit format

## Instructions

1. Guide reverse image search process
2. Classify fair use vs clear reuse
3. Draft attribution or removal requests
4. Track preferred credit HTML

## Output

Cases list + request templates

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
