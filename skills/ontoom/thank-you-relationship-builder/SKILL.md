# Thank-you relationship builder

## Goal

Turn a one-off publication into a recurring partner with a thank-you note.

## Inputs

Published URL + editor name

## Instructions

1. Write short thank-you referencing the piece
2. Offer a future exclusive angle
3. Ask how to be helpful next time
4. Optional social amplification draft

## Output

Thank-you + next-angle offer

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
