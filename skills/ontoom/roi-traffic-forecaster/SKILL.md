## Goal

Estimate organic traffic potential and paid-media equivalent value for keyword groups.

## Inputs

## Instructions

1. State assumptions clearly
2. Compute ranges not false precision
3. Map to revenue if conversion rate given
4. Call out uncertainty

## Output

Forecast table + assumptions
