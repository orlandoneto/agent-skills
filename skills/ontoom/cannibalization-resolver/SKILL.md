# Cannibalization resolver

## Goal

Detect pages competing for the same term and recommend merge or redirect.

## Inputs

Keyword + candidate URLs

## Instructions

1. Compare intent overlap
2. Pick winner URL
3. Recommend consolidate/redirect/differentiate
4. Outline internal link changes

## Output

Resolution plan

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
