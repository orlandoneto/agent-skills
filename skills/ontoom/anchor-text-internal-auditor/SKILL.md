# Internal anchor text auditor

## Goal

Ensure internal anchors are descriptive instead of 'click here'.

## Inputs

Internal link export or HTML samples

## Instructions

1. Flag weak anchors
2. Propose descriptive replacements
3. Check over-optimization of exact match
4. Group by template issues

## Output

Anchor fix list

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
