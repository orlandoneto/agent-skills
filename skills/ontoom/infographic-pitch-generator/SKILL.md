# Infographic pitch generator

## Goal

Find blogs that publish visuals and pitch exclusive infographics for credit links.

## Inputs

Topic + data points + target URL

## Instructions

1. Outline a unique data visual concept
2. Suggest prospect types that embed visuals
3. Write pitch emphasizing exclusivity and embed code
4. List attribution requirements

## Output

Concept brief + pitch email

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
