# Partnership proposal builder

## Goal

Structure co-marketing proposals that create natural authority exchange.

## Inputs

Partner type + shared audience + assets

## Instructions

1. Define mutual outcomes
2. Propose formats (webinar, ebook, data study)
3. Outline responsibilities and timeline
4. Include link/mention expectations transparently

## Output

1-page partnership proposal

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
