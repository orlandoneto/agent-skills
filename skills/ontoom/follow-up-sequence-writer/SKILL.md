# Follow-up sequence writer

## Goal

Create a polite 3-email follow-up cadence for non-responders.

## Inputs

Original email + ask + value prop

## Instructions

1. Write day-3, day-7, day-14 follow-ups
2. Vary angle (value, social proof, soft close)
3. Keep each under 90 words
4. Never guilt-trip

## Output

3 follow-up emails with timing

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
