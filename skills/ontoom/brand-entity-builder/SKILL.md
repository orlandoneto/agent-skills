# Brand entity builder

## Goal

Create consistent brand/founder copy to strengthen Knowledge Graph signals.

## Inputs

Company facts + official profiles

## Instructions

1. Write canonical About blurbs
2. Align NAP/sameAs candidates
3. Avoid unverifiable claims
4. Suggest schema Person/Organization fields

## Output

Entity pack

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
