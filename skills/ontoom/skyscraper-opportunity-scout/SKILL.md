# Skyscraper opportunity scout

## Goal

Find ranking pages with many backlinks and list ways to make a 10x better asset.

## Inputs

Seed keyword or competitor URL

## Instructions

1. Outline the top page structure and angles
2. List content gaps, outdated data, weak media
3. Propose a superior outline with unique assets
4. List who likely linked to the original for outreach

## Output

Brief: gaps, outline, outreach target types

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
