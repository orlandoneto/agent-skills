# Niche edit prospector

## Goal

Find aged indexed articles where a contextual link to the user's guide adds value.

## Inputs

Target guide URL + niche keywords

## Instructions

1. Find topical articles with resource sections
2. Suggest exact paragraph/context for the link
3. Assess relevance (no irrelevant insertions)
4. Draft value-first outreach

## Output

Prospects with suggested anchor + context

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
