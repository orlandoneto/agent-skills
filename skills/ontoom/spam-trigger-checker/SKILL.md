# Spam trigger checker

## Goal

Review outreach templates and remove spam-filter triggers.

## Inputs

Email template(s)

## Instructions

1. Flag trigger words, ALL CAPS, excess links
2. Check link/domain reputation notes
3. Suggest cleaner wording
4. Keep one clear CTA link

## Output

Annotated template + clean version

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
