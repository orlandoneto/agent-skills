# HARO / Connectively responder

## Goal

Draft short, citable answers to journalist queries based on the user's expertise.

## Inputs

Topic expertise notes + journalist question (or HARO dump)

## Instructions

1. Extract the question and deadline
2. Match claims the user can verify
3. Write a 80–150 word quotable answer with one proof point
4. Add a one-line bio + optional link

## Output

Ready-to-paste reply + optional subject line

## Rules

- Do not invent rankings, backlink metrics, or API data you cannot see.
- Prefer official exports/APIs over scraping that violates site ToS.
- No black-hat advice (PBNs, cloaking, fake reviews, spam comments).
- Default language: match the user's content language (pt-BR if they write in Portuguese).
